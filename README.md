# Student-data-Excel-file
The dataset contains records of 150 students along with their academic performance, gender, location, and overall grade. It is designed for practicing Excel operations, data cleaning, analysis, and visualization tasks.  Dataset Features Student_ID: Unique identification number for each student. Name: Student names generated randomly.


Dataset Features


Student_ID: Unique identification number for each student.


Name: Student names generated randomly.


Gender: Includes male and female values.


Raw data contains inconsistent values such as Male, Female, m, and f.


Cleaned data standardizes them into only M and F.




Location: City names of students.


Raw data intentionally includes extra spaces and inconsistent capitalization.


Cleaned data removes spaces and converts names into proper title case.
